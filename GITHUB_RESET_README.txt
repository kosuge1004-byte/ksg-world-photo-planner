AstroSight GitHub clean baseline
Created: 2026-08-21

Purpose:
- Replace the entire existing GitHub repository contents with this package.
- Contains source/configuration/native Android project and required static assets.
- Historical implementation reports, node_modules, build output, caches, and generated Android web assets are excluded.

After replacing the repository contents:
1. npm ci
2. npm run build
3. For Android when needed: npm run android:sync

Important:
- Do not commit .env, .dev.vars, API tokens, local.properties, node_modules, dist, or generated Android assets.
- public/__astro_internal_geo_tz is generated automatically by npm prebuild from the geo-tz package.
- android/app/src/main/assets/public is generated by Capacitor sync/build and is intentionally excluded.
