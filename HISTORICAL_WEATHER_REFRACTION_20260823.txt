AstroSight 過去日付の気象連動屈折補正 修正

- 過去日付は5年平年値ではなく Open-Meteo Historical Weather API の時間別過去気象を使用。
- 使用値: 2m気温 / 2m相対湿度 / 地表気圧。
- 選択時刻に最も近い時間別サンプル（90分以内）を既存の Bennett 屈折補正式へ入力。
- 過去データは historical 専用キャッシュへ保存。
- 当日〜7日先は予報、7日より先の未来のみ平年値を維持。
- API取得失敗時は従来どおり標準大気へフォールバック。

注意:
Open-Meteo Historical Weather API は観測所の生データそのものではなく、観測値（気象台・航空機・ブイ・レーダー・衛星等）と数値モデルを統合した再解析/履歴気象データ。世界の任意地点で一貫して使える過去実績相当データとして採用。
