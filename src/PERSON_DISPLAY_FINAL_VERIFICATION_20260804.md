# 人物配置・描画 最終検証（2026-08-04）

## 確認済み仕様

- 被写体ピン位置へ配置した人物は、被写体ピンの3D高度を保持する。
- 3Dマップで配置・ドラッグした人物は、取得した3D表面高度を保持する。
- 2Dマップから配置した場合だけ、DEM・地形高度による補正を行う。
- 上部プレビューは距離に関係なく実寸人物シルエットを表示する。
- 人物が被写体ピンから0.5m以内の場合、上部プレビューの被写体中心ピンを非表示にする。
- 3Dマップは100m以内で実寸人物シルエット、100m超で固定ピクセル人物ピンを表示する。
- 2Dマップは距離・ズームに関係なく固定ピクセル人物ピンを表示する。
- 人物高さはcmで保存し、幾何計算時だけmへ変換する（170cm = 1.70m）。
