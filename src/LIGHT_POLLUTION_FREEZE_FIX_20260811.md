# 光害マップON時の暗転・フリーズ修正

原因は、NASA GIBS `VIIRS_Black_Marble` の最大ズームが8なのに、2D地図がそれ以上のズーム（例: 17）になったとき、z=8の256pxタイルを `256 * 2^(mapZoom-8)` px のDOM画像として拡大していたことです。ズーム17では1枚あたり131,072px四方相当となり、ブラウザ/GPUのメモリを大量消費して画面が固まる可能性がありました。

修正内容:
- DOM `<img>` の巨大拡大を廃止。
- 表示領域と交差するz=8タイルの必要部分だけをCanvasへ描画。
- Canvas自体は常に地図表示サイズまでに制限（DPRは最大2）。
- タイル読込失敗時に画面を暗くしないよう、オーバーレイ背景を透明化。
- 古いズーム/位置の非同期読込結果は世代番号で破棄。
- クレジットは少なくとも1枚のタイル描画成功後のみ表示。
