# 前景・中景オブジェクト配置と人物縮尺の修正

## 修正内容

- 被写体・三脚・人物の配置状態を単一の配置モードで排他的に管理
- 人物配置が被写体ピン変更へ切り替わる競合を防止
- 2D人物配置から不要な3Dビューア準備条件を削除
- 三脚と被写体の間にある有効なタップ地点を、その座標のまま保持
- 被写体より奥、三脚より手前の人物配置を拒否
- 3Dドラッグ処理と各ピン配置処理の同時起動を防止

## 人物の縮尺

- フルサイズセンサー寸法と焦点距離によるピンホール投影へ変更
- 三脚のレンズ中心、人物の地上位置と身長、被写体方向から画面座標を計算
- 縦横構図のアスペクト比を含め、CSS上の幅と高さを実寸投影へ補正
- 3Dでは人物高をメートル指定した地表固定ビルボードとして表示

## 確認結果

- 人物配置ボタンから「前景・中景オブジェクトを置く地点を選択」へ遷移
- 2Dマップ上で人物170cmを配置
- プレビュー上の人物表示を確認
- 24mmから48mmへの変更で人物表示高が約2倍になることを確認
- 自動検証で焦点距離倍率2.0、人物縦横比0.4を確認
- `npm run lint` 成功
- `npm run build` 成功
- ブラウザ警告・エラー0件
