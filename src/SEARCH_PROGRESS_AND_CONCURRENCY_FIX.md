# スポット検索進捗表示・検索並行動作修正

## 修正内容
- スポット検索のバックグラウンドジョブに `progressPercent` を追加。
- 日時サンプル確認数を基準に0〜95%、地点情報取得を97%、端末側3D確認を98〜100%として表示。
- 旧保存ジョブに `progressPercent` がない場合は0%へフォールバック。
- スポット検索画面に通過日時検索と同形式の進捗ゲージ・百分率を追加。
- 通過日時検索中にダイアログを閉じても検索処理を中断しないよう変更。
  これにより通過日時検索を継続したままスポット検索を開始できる。
- 通過日時検索画面を再度開いた場合、進行中の検索状態を維持する。
