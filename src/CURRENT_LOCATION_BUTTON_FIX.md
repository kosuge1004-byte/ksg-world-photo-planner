# 現在位置ボタン修正

- HTTPS接続でない場合を明示
- GPS高精度取得を実行
- タイムアウト・取得不能時は通常精度へ自動再試行
- 位置情報拒否、取得不能、タイムアウトを日本語で区別表示
- 取得座標を mapCenter と mapCenterRef の両方へ即時反映
- 3D表示時は現在地へカメラ移動
- 取得精度を結果メッセージへ表示
- 重複リクエスト時に古い結果が後から上書きしないよう requestId を追加
- Web/PWAでは対象アプリが表示されない端末全体のGPS設定を開かない
- Web/PWAでは対象サイト名を表示し、Chrome/Safariのサイト権限変更手順を案内
- Android/iOSネイティブ版では、アプリ個別設定専用ブリッジだけを使用
- 権限案内メッセージへ「閉じる」ボタンを追加
