# スポット検索高速化

## 実装内容

- 日時の軽量条件判定と、三脚位置・見通しの精密検査を分離
- 精密検査を一定件数の候補日時単位で実行
- 三脚候補計算を同時2件に制限して並列化
- 三脚候補を先に絞り、見通し確認を後段で同時2件処理
- 近い方位で得た前回三脚距離を次候補の初期探索範囲に再利用
- 再利用範囲で解がない場合は全距離範囲へ自動フォールバック
- 標準モード: 初回16点・精密化2段階・6分割
- Proモード: 初回32点・精密化3段階・8分割
- 結果は日時順を維持
- 停止シグナルを各段階で確認
