## ビルド方法について

この環境の既存 `node_modules` はWindows用で、Vite 8が必要とするLinux版Rolldownネイティブバインディングが含まれていませんでした。また、依存関係の再取得はnpm側のHTTP 503で完了しませんでした。

そのため、`npm run build` の成功を装わず、利用可能なTypeScriptと純JavaScript版Rollupを使用して現在のソースを本番ESモジュールへ生成しました。Cesiumは同梱済みの公式ブラウザビルドを `window.Cesium` として読み込み、Workers等を `/cesium/` から参照します。
