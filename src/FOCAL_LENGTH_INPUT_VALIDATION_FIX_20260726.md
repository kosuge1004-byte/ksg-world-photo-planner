# 焦点距離入力修正

## 原因

上部の焦点距離入力は、1文字変更するたびに値を9～1600へ補正していました。
そのため、既存値を消した瞬間に9へ戻り、40や50へ打ち直せませんでした。

## 修正

- 入力中の文字列と撮影計算用の焦点距離を分離
- 入力中は空欄、8以下、1601以上を含めて自由に編集可能
- 9～1600へ入った値はプレビューへリアルタイム反映
- 入力欄から離れた時だけ範囲を検証
- 無効な場合は「焦点距離には9～1600の数字を入力してください。」と表示
- 警告は「閉じる」、背景タップ、Escキーで閉じられる
- 無効な入力値は撮影計算へ渡さず、最後の正常値を維持

## 検証

- 9から40への打ち直し
- 50の入力
- 境界値9、1600
- 範囲外8、1601
- 小数24.5
- 全角数字50
- 空欄、数字以外
- 警告の表示と閉じる操作
- TypeScriptビルド
- Lint
- Capacitor Android同期
- Google Maps URL回帰テスト
