# 起動時メイン画面固定修正

## 変更内容
- アプリ起動時にスポット検索画面へ自動遷移していた処理を廃止。
- 起動時は必ず「プレビュー画面＋マップ画面」のメイン2画面を表示。
- 保存済みのスポット検索ジョブ自体は削除せず、検索画面を手動で開いた際に再開可能。
- ブラウザのページ復元（BFCache）時にも検索画面などの全画面オーバーレイを閉じ、メイン画面へ戻す。

## 対象ファイル
- `src/App.tsx`

## 確認
- 初期状態で各全画面画面の open state が false になる処理を確認。
- `pageshow` の persisted 復元時もメイン画面へ戻す処理を確認。
