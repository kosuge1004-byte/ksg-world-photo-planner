# Workers KV PUT削減 第4段階

## 変更内容

- `/api/spot-search-start` を冪等化した。
- 同じ `clientId` / `jobId` / 検索条件で開始APIが再送された場合、既存ジョブを返し、次を実行しない。
  - `KV.put()`
  - Queueへの重複送信
- 同じジョブIDへ異なる検索条件が送られた場合は409を返す。

## 効果

通信再送、二重タップ、ブラウザの再試行などによる `queued` の重複PUTと重複検索を防止する。
通常の新規検索のPUT上限は従来どおり3回だが、同一開始要求の再送は0回になる。

## 現在のWorkers KV PUT

1. 新規検索開始: `queued` 1回
2. サーバー検索完了: `awaiting-3d` 1回
3. 端末3D確認完了: `complete` 1回

進捗、時間軸、日時、三脚候補更新、DEM取得、人物・カメラ操作では0回。
