# スポット検索 DEM障害対策・診断表示

## 実装内容

- DEM先行取得失敗を診断件数へ記録。
- 三脚候補計算例外を診断件数へ記録。
- 見通し用DEM取得失敗時は候補を即時破棄せず、「地形未確認候補」として端末側の最終3D遮蔽確認へ送る。
- 三脚候補が一件も成立せず計算例外だけが発生した場合、候補0件ではなく検索処理エラーとして表示。
- 検索完了時に日時候補、天体条件通過、三脚候補、DEM失敗、見通し確認、最終3D通過件数を表示。
- Promiseキャッシュは既存実装で失敗Promiseを自動削除することを確認。
