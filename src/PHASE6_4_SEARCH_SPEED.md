# Phase6-4 検索速度改善

## 対象

- スポット検索の日時走査
- 天体通過日時検索の日時走査
- 曜日・時間帯フィルター

## 実装内容

1. 1サンプル内のタイムゾーン変換を共有
   - 従来は曜日判定と時間帯判定がそれぞれ `zonedDateTimeLocalFromDate()` を実行していた。
   - `localSearchDateParts()` で現地曜日と現地分時刻を一度に算出し、両判定で共有する。

2. 曜日条件を Set 化
   - 各サンプルでの `Array.includes()` を `Set.has()` に変更した。
   - 曜日未指定時は Set 自体を作成しない。

3. 時間帯判定を数値入力対応に分離
   - `isMinuteWithinSearchRange()` を追加し、既に求めた現地分時刻を直接判定する。
   - 日付またぎ条件（例: 22:00〜02:00）の意味は変更していない。

## 互換性

- 検索期間、サンプル間隔、天体計算、候補計算、LOS判定は変更していない。
- タイムゾーンおよびDSTは従来どおり `zonedDateTimeLocalFromDate()` を基準とする。
- 検索結果の採用条件と並び順は変更していない。
