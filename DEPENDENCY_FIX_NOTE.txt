修正内容
========
元ZIPに同梱されていた node_modules は不完全で、以下の型定義が欠損していました。
- vite/client
- @types/node

node_modules はOS・Node.js環境依存の生成物であり、ソース配布ZIPには通常同梱しません。
この修正版では壊れた node_modules を削除し、package-lock.json に基づき npm ci で正確に再構築する形に修正しました。

Windowsでの検査
================
1. Node.js 22系をインストール
2. BUILD_VERIFY_WINDOWS.bat を実行
3. "Build completed successfully" と表示されることを確認

手動コマンド
============
npm ci
npm run build

注意
====
依存関係の初回取得にはインターネット接続が必要です。
